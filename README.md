## Laravel Portfolio - Backend (API)

Questo progetto rappresenta il backend del portfolio ed è sviluppato con **Laravel**.  
Gestisce i dati relativi a:
- Progetti
- Tipologie (Types)
- Tecnologie (Technologies)

Fornisce API pubbliche per il frontend e un pannello admin con CRUD completo.


### Partenza

1. installare le dipendenze di npm e composer
2. inserire dati nel file .env
3. far partire le migrations
4. avviare il server (php e node)
